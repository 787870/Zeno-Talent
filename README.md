# AI-Powered NHS Waiting List & Appointment Optimization

**Domain:** Data Analytics Internship Capstone

**Project Status:** Completed ✅

### Project Overview
This repository contains the final Power BI dashboard and analytical report for the July 2026 NHS Referral to Treatment (RTT) data extract. The project focuses on visualizing the 7.16 million patient backlog to identify key bottlenecks across medical specialties and regional care boards.

### Key Deliverables
* **`NHS Waiting List Optimization.pbix`:** An interactive Power BI dashboard featuring custom DAX measures, dynamic regional filtering, and customized visual analytics.
* **`NHS Waiting List Optimization.pdf`:** A static, executive-ready snapshot of the final dashboard layout.
* **Data Engineering:** Utilized Power Query to clean raw NHS extracts, filter active waitlist pathways (Part_2), remove duplication totals, and replace null values to ensure accurate aggregations.
